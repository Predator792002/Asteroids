# Asteroids Game

## Overview

Asteroids is a classic arcade-style space shooter game built using Python and Pygame. Players navigate a spaceship in an asteroid field, shooting and dodging asteroids while attempting to survive as long as possible. Larger asteroids break into smaller ones when hit, adding to the challenge.

## Features

- Player-controlled spaceship with smooth movement
- Shooting mechanics to destroy asteroids
- Asteroids split into smaller pieces upon destruction

## Installation

### Prerequisites

- Python 3.x
- Pygame

### Steps

1. Clone this repository:

   ```sh
   git clone https://github.com/yourusername/asteroids.git
   cd asteroids
   ```

2. Create a virtual environment (optional but recommended):

   ```sh
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```

3. Install dependencies:

   ```sh
   pip install -r requirements.txt
   ```

4. Run the game:

   ```sh
   python main.py
   ```

## Controls

- **WASD Keys**: Move the spaceship
- **Spacebar**: Shoot bullets

## How It Works

- The game starts with large asteroids floating across the screen.
- When shot, large asteroids split into smaller ones, making the game progressively harder.
- The goal is to survive as long as possible.
